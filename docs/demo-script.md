# 评审视频演示脚本（建议 3~5 分钟）

> 拍摄前准备：手机电量 >30%；使用教练卡参数先恢复正常值；屏幕录制 1080p；
> 提前打开一次 app 确认通知权限已授权（收得到通知才拍得到）。

## 分镜 1：开场 — 数字健康教练（30s）

- 桌面点开 PhonePulse
- 主页展示：**亮屏计时走动**、"屏幕点亮运行中 / 后台常驻守护"徽章、伙伴卡片
- 旁白点：实时感知屏幕状态，所有数据纯本地

## 分镜 2：电量统计页 — 一屏看全（40s）

- 底部 tab「电量统计」：
  - 电量曲线（今日充放电轨迹）
  - **应用使用排行**（今日各 app 前台时长）
  - 滚到「使用教练」卡片停住

## 分镜 3：使用教练 — 可调参数 + 两级提醒（60s，核心演示）

1. 打开使用教练卡：**预算填 1、连续上限填 1 → 保存**（旁白：参数全部可调，即时生效）
2. 正常滑动操作手机约 1 分钟
3. **通知栏下拉：两条提醒到手**
   - "今日亮屏预算已用 80%"（预警）
   - "已连续使用 X 分钟"（休息建议）
4. 回 app 把参数改回正常值（如预算 240）
- 旁白点：提醒有每日冷却，不轰炸；文案中性不评判

## 分镜 4：电池健康 — 证据链（60s）

- 底部 tab「电量统计」→ 顶部「电池健康」
- 展示：
  - **容量保持率 + 估算实际容量**（徽标：快速证据/正式估算——旁白：区分置信度，不假装精确）
  - **设计容量：机型标称 5000 mAh**（旁白：自动识别机型，免手填）
  - **容量趋势图**（多次充电记录）
  - 充放记录 tab：每次充电的跨度/时长/电荷明细
- 旁白点（可选，技术亮点）：对照系统自建容量学习值交叉验证，我们的方法能检测系统级传感器口径问题

## 分镜 5：充电保护（30s）

- 插上充电器 → 充电提醒 tab：
  - 目标电量（80%）设置 → 到 80% 收通知（可提前把目标设为当前+5% 演示）
  - 测量校准（高级）：反转电流方向开关——旁白：针对不同厂商传感器口径可校准

## 分镜 6：隐私收尾（20s）

- 系统设置 → 应用 → PhonePulse → 权限：**无网络权限**
- 旁白收尾：所有数据本地存储，绝不联网上传——数字健康，从尊重隐私开始

## 拍摄注意

- 教练演示（分镜 3）先试拍一遍：预算 1 分钟时预警和总结可能 1 分钟内连发，注意通知栏时间
- 健康度数字若显示"快速估算"，旁白口径用"证据持续积累中"（不要说"不准"）
- 每个分镜单独录，后期剪辑更稳
